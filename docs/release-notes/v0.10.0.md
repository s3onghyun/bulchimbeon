## English

### Highlights

- **Lid-closed duty ends cleanly.** When you approve lid-closed duty, Bulchimbeon starts a
  root watchdog that restores normal sleep settings as soon as duty ends—including a timer
  expiring, ending duty from the menu, switching to a non-lid duty, or quitting the app.
  Closing the lid while duty ends no longer needs a second administrator-password prompt.
  The watchdog remains available while you change duty, so that change does not need a new
  approval. Bulchimbeon also rechecks the real `pmset` state, so an external restoration is
  reflected in the menu. (#51)
- **A gentler first run.** A welcome item in the menu explains how to start, and the README now
  opens with a quick-start path. New contributors can also browse `good first issue` tasks. (#50)

Linux daemon: no change.

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.10.0.zip` below.
- **Linux:** Homebrew, tarball, `.deb` and `.rpm` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.10.0/CHANGELOG.md).

## 한국어

### 주요 변경

- **덮개를 닫은 근무도 깔끔하게 끝납니다.** 덮개 닫힘 근무를 승인하면 Bulchimbeon이 root 감시병을 띄워
  타이머 만료, 메뉴에서 근무 종료, 덮개 없는 근무로 전환, 앱 종료 때 즉시 일반 잠자기 설정을 되돌립니다.
  덮개가 닫힌 상태에서 근무가 끝나도 두 번째 관리자 암호 창은 뜨지 않습니다. 근무 방식을 바꿔도 감시병이
  계속 준비되어 새 승인이 필요 없습니다. Bulchimbeon은 실제 `pmset` 상태도 다시 확인하므로, 밖에서
  잠자기 설정을 되돌리면 메뉴에 그대로 반영합니다. (#51)
- **처음 실행을 더 쉽게 안내합니다.** 메뉴의 환영 안내가 시작 방법을 보여 주고, README 첫 화면에도
  빠른 시작 경로를 넣었습니다. 새 기여자는 `good first issue` 작업을 골라볼 수 있습니다. (#50)

리눅스 데몬: 변경 없음.
