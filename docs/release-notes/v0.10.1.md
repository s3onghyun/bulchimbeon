## English

### Highlights

- **Lid-closed duty stays your choice.** If a lid-closed watch has to fall back to a system
  watch (the app restarts or updates mid-watch, you cancel the administrator prompt, or duty
  resumes after a heat rest), only that watch falls back. The menu keeps lid-closed duty
  checked instead of switching to `caffeinate -i`, shows "this watch fell back to system watch"
  under the duty mode while it lasts, and the next watch asks for lid approval again. If an
  earlier version already saved system watch, pick lid-closed duty once more in the menu. (#54)

Linux daemon: no change.

### Check after upgrading

Start a lid-closed watch, restart the app, then Stop: lid-closed duty should still be checked.

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.10.1.zip` below.
- **Linux:** Homebrew, tarball, `.deb` and `.rpm` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.10.1/CHANGELOG.md).

## 한국어

### 주요 변경

- **덮개 닫힘 근무는 고른 그대로 남습니다.** 덮개 닫힘 근무가 시스템 근무로 대체되어도(근무 중 앱 재시작·업데이트,
  관리자 암호 창 취소, 과열 뒤 복귀) 그 근무만 대체됩니다. 메뉴 체크는 `caffeinate -i` 로 바뀌지 않고 덮개 근무로
  남으며, 대체 근무 동안 근무 형태 아래에 "이번 근무는 시스템 근무로 대체됨" 을 보이고, 다음 근무는 다시 덮개 승인을
  묻습니다. 이전 버전에서 이미 시스템 근무로 저장됐다면 메뉴에서 덮개 근무를 한 번 다시 고르세요. (#54)

리눅스 데몬: 변경 없음.

### 업그레이드 뒤 확인

덮개 근무를 시작하고 앱을 다시 실행한 뒤 근무를 멈추세요. 덮개 근무 체크가 그대로 남아 있어야 합니다.
