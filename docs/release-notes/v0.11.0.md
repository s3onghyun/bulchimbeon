## English

**Bulchimbeon now tells you when a new version is out.** Once a day the app and the Linux
daemon check GitHub Releases for the latest version. On macOS you can update in one click.

> **This release does not announce itself.** The update check ships in 0.11.0, so 0.10.2 and
> older will not show an in-app notice for it. Upgrade once by hand (see Install below); from
> this version on, future releases show up in the menu.

### Highlights

- **New version in the menu.** When a newer release exists, the menu shows
  "New version X.Y.Z — Update" and "Release notes". Releases that carry an important fix
  are marked "(recommended: important fix)". (#60)
- **One-click update on macOS.** Nothing installs until you click and confirm. Homebrew
  installs run `brew update && brew upgrade --cask bulchimbeon` in a visible Terminal window
  and reopen the app. Other installs download the release zip and its `.sha256`, check the
  checksum, verify that the new app's code signature is valid, has the same signing identifier
  and team ID as the running app and uses the hardened runtime, and only then replace the app
  and relaunch. If anything fails, the installed app is left untouched and the reason and the
  release page are shown. (#60)
- **Linux: notices only.** `bulchimbeon status`, the tray menu and `bulchimbeon doctor` show the
  new version and the right command for how you installed it (`.deb`, `.rpm`, AUR, Homebrew or
  tarball); the daemon logs one line to the journal. Nothing is installed automatically. (#60)

### Privacy

The check is a single HTTPS GET to
`api.github.com/repos/s3onghyun/bulchimbeon/releases/latest`, at most once a day, with only the
`User-Agent: Bulchimbeon/<version>`, `Accept` and a fixed `Accept-Language: en` headers. No
settings, duty log or identifiers are sent, and there is no telemetry. It is the only network
traffic Bulchimbeon makes. To turn it off, untick "Check for updates (once a day)" in the
menu, or set `checkForUpdates` to false:
`defaults write io.github.s3onghyun.bulchimbeon checkForUpdates -bool false` on macOS,
`bulchimbeon config set checkForUpdates false` on Linux.

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.11.0.zip` below.
- **Linux:** Homebrew, AUR, tarball, `.deb` and `.rpm` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

## 한국어

**이제 불침번이 새 버전이 나오면 알려 줍니다.** 앱과 리눅스 데몬이 하루 한 번 GitHub Releases 에서 최신 버전을
확인합니다. macOS 에서는 한 번 눌러 업데이트할 수 있습니다.

> **이번 릴리스는 메뉴에 뜨지 않습니다.** 업데이트 확인이 0.11.0 에 처음 들어가므로 0.10.2 이하에서는 앱 안에 알림이
> 보이지 않습니다. 이번 한 번은 직접 업그레이드하세요 (아래 설치). 이 버전부터는 다음 릴리스가 메뉴에 나타납니다.

### 주요 변경

- **메뉴에 새 버전.** 더 새 릴리스가 있으면 메뉴에 "새 버전 X.Y.Z — 업데이트" 와 "릴리스 노트 보기" 가 보입니다.
  중요 수정이 든 릴리스에는 "(권장: 중요 수정)" 이 붙습니다. (#60)
- **macOS 한 번에 업데이트.** 누르고 확인하기 전에는 아무것도 설치하지 않습니다. Homebrew 로 설치했으면 보이는 터미널
  창에서 `brew update && brew upgrade --cask bulchimbeon` 을 실행하고 앱을 다시 엽니다. 그 밖에는 릴리스 zip 과
  `.sha256` 을 받아 체크섬을 맞추고, 새 앱의 코드 서명이 유효한지, 서명 식별자·팀 ID 가 지금 앱과 같은지, hardened
  runtime 인지 확인한 뒤에만 앱을 바꾸고 다시 시작합니다. 실패하면 설치된 앱은 그대로 두고 까닭과 릴리스 페이지를
  보입니다. (#60)
- **리눅스: 알림만.** `bulchimbeon status`·트레이 메뉴·`bulchimbeon doctor` 가 새 버전과, 설치한 방법(`.deb`,
  `.rpm`, AUR, Homebrew, tarball)에 맞는 명령을 보이고 데몬이 저널에 한 줄 남깁니다. 자동으로 설치하지 않습니다. (#60)

### 개인정보

확인은 하루 한 번 이하, `api.github.com/repos/s3onghyun/bulchimbeon/releases/latest` 에 대한 HTTPS GET 하나이고,
머리글은 `User-Agent: Bulchimbeon/<버전>`·`Accept`·고정값 `Accept-Language: en` 뿐입니다. 설정·근무일지·식별자는
보내지 않고 텔레메트리는 없습니다. 불침번의 유일한 네트워크 통신입니다. 끄려면 메뉴의 "새 버전 확인 (하루 한 번)" 을
해제하거나 `checkForUpdates` 를 끄세요: macOS
`defaults write io.github.s3onghyun.bulchimbeon checkForUpdates -bool false`, 리눅스
`bulchimbeon config set checkForUpdates false`.

### 설치

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, 새 설치는
  `brew install --cask s3onghyun/tap/bulchimbeon`. 또는 아래 `Bulchimbeon-0.11.0.zip`을 받으세요.
- **Linux:** Homebrew·AUR·tarball·`.deb`·`.rpm` 설치는 [README → Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1)을
  보세요. 데몬이 하나만 돌도록 설치 방법은 하나만 고르세요.

릴리스 파일은 게시된 SHA-256 체크섬으로 검증한 뒤
`gh attestation verify <파일> --repo s3onghyun/bulchimbeon`을 실행하세요.
