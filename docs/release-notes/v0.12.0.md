## English

**Bulchimbeon works right after install: Agent watch is on at first launch.** A fresh install
now starts watching your AI coding agents without any extra click, so the Mac stays awake
while they work and is free to sleep when they are done.

**Existing users keep their saved choice.** If you have used Bulchimbeon before, nothing
changes: Agent watch off, a timed watch or any duty mode you picked stays exactly as you left it.

### Highlights

- **Agent watch on at first launch (macOS).** Only when nothing is saved yet (no duty order,
  duty mode or welcome seen) does the app start with Agent watch ticked. The duty log records
  "First launch - agent watch on by default", and the welcome panel shows how to untick it.
  Battery floor and heat safeguards are unchanged. The Linux daemon already watches agents
  whenever it runs, so it behaves the same. (#66)
- **Install with your AI agent.** Paste one prompt into Claude Code, Codex, Gemini CLI or
  another coding agent and it installs Bulchimbeon step by step, showing each command first and
  stopping when you need to click **Open Anyway**. The agent follows
  <https://raw.githubusercontent.com/s3onghyun/bulchimbeon/main/docs/install-for-agents.md>;
  the prompt is in the README, and `llms.txt` points agents to it. (#65)
- **New "Start here" in the README.** The first-launch Gatekeeper steps are inline with a
  screenshot, followed by a 1-minute check that Bulchimbeon is really keeping the Mac awake. (#63)

### Install

- **macOS:** use "New version 0.12.0 — Update" in the menu (0.11.0 and later), or
  `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.12.0.zip` below.
- **Linux:** Homebrew, AUR, tarball, `.deb` and `.rpm` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.12.0/CHANGELOG.md).

## 한국어

**설치하면 바로 일합니다: 처음 실행할 때 에이전트 근무가 켜져 있습니다.** 새로 설치하면 따로 체크하지 않아도
AI 코딩 에이전트를 지키기 시작해, 에이전트가 일하는 동안 맥을 깨워 두고 끝나면 잠들게 둡니다.

**기존 사용자는 저장된 선택을 그대로 씁니다.** 불침번을 써 왔다면 바뀌는 것이 없습니다. 에이전트 근무를 껐거나
시간 근무 중이었거나 고른 근무 형태는 그대로입니다.

### 주요 변경

- **첫 실행에 에이전트 근무 켬 (macOS).** 저장된 것이 하나도 없을 때(근무 명령·근무 형태·환영 안내 기록 없음)만
  에이전트 근무가 체크된 채 시작합니다. 근무일지에 "첫 실행 — 에이전트 근무 기본으로 켬" 을 남기고, 환영 안내에
  끄는 법을 보입니다. 배터리 하한과 폭염 대응은 그대로입니다. 리눅스 데몬은 원래 실행되면 늘 에이전트 근무라
  바뀌지 않습니다. (#66)
- **AI 에이전트로 설치.** Claude Code·Codex·Gemini CLI 같은 코딩 에이전트에 안내문 하나를 붙여 넣으면, 명령을
  먼저 보여 주며 한 단계씩 설치하고 **Open Anyway** 를 눌러야 할 때 멈춥니다. 에이전트는
  <https://raw.githubusercontent.com/s3onghyun/bulchimbeon/main/docs/install-for-agents.md> 를 따릅니다.
  안내문은 README 에 있고 `llms.txt` 가 에이전트에게 이 문서를 알려 줍니다. (#65)
- **README 의 새 "Start here".** 첫 실행 Gatekeeper 단계를 스크린숏과 함께 바로 보이고, 불침번이 정말 맥을 깨워
  두는지 1분 안에 확인하는 법을 더했습니다. (#63)
