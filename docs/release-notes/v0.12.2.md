## English

**Stand watch works again.** In 0.12.1, clicking a duration under **🪖 Stand watch** (30 min, 1 hour…)
often did nothing. The menu-bar sprite's frame counter belonged to the whole app, so every frame
(every 0.5 seconds) rebuilt the entire menu. Since 0.12.1 that timer also ran while the menu was open,
so the submenu items changed under the pointer and the click was lost. The counter now redraws only
the menu-bar icon. (#73)

This release is not marked critical. The bug blocked starting a timed watch from the menu but did not
lose data or weaken security, and agent watch, the battery floor and the heat safeguards kept working.

### Install

- **macOS:** use "New version 0.12.2 — Update" in the menu (0.11.0 and later), or
  `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.12.2.zip` below.
- **Linux:** nothing changed for the Linux daemon in this release. Homebrew, AUR, tarball, `.deb` and
  `.rpm` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.12.2/CHANGELOG.md).

## 한국어

**근무 서기가 다시 됩니다.** 0.12.1 에서는 **🪖 근무 서기** 아래의 시간 항목(30분·1시간…)을 눌러도 아무 일이
없을 때가 많았습니다. 메뉴바 이등병의 프레임 카운터를 앱 전체가 들고 있어 프레임마다(0.5초마다) 메뉴 전체가 다시
만들어졌고, 0.12.1 부터 그 타이머가 메뉴가 열린 동안에도 돌아 누르는 사이에 하위 메뉴 항목이 바뀌어 클릭이
사라졌습니다. 이제 카운터는 메뉴바 아이콘만 다시 그립니다. (#73)

이 릴리스는 중요 수정으로 표시하지 않았습니다. 이 버그는 메뉴에서 시간제 근무를 시작하지 못하게 했지만 데이터를
잃거나 보안을 약하게 하지 않았고, 에이전트 근무·배터리 하한·폭염 대응은 그대로 작동했습니다.

### 설치

- **macOS:** 메뉴의 "새 버전 0.12.2 — 업데이트" (0.11.0 이상), 또는 `brew update && brew upgrade --cask bulchimbeon`,
  새 설치는 `brew install --cask s3onghyun/tap/bulchimbeon`. 또는 아래 `Bulchimbeon-0.12.2.zip`을 받으세요.

  [README → Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1)을 보세요. 데몬이 하나만 돌도록
  설치 방법은 하나만 고르세요.

릴리스 파일은 게시된 SHA-256 체크섬으로 검증한 뒤
`gh attestation verify <파일> --repo s3onghyun/bulchimbeon`을 실행하세요.
