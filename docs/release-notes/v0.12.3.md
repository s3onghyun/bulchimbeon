## English

**Stand watch can be picked again, for real this time.** In 0.12.2, hovering **🪖 Stand watch** made its
submenu flicker and disappear, often taking the whole menu with it, so no duration could be chosen. Since
0.12.1 the app watches whether the menu-bar icon is covered, so the sprite can rest while nobody sees it. That
signal arrives every time any of the app's windows opens or closes, the menu and the submenu included, and
each one rebuilt the whole menu. The rebuilt submenu window sent the signal again, so it looped 10–30 times a
second while the pointer was on the submenu. The signal now counts only when the value changes, and only the
menu-bar icon listens to it. (#77)

This release is not marked critical. The bug blocked starting a timed watch from the menu but did not
lose data or weaken security, and agent watch, the battery floor and the heat safeguards kept working.

### Install

- **macOS:** use "New version 0.12.3 — Update" in the menu (0.11.0 and later), or
  `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.12.3.zip` below.
- **Linux:** nothing changed for the Linux daemon in this release. Homebrew, AUR, tarball, `.deb` and
  `.rpm` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.12.3/CHANGELOG.md).

## 한국어

**이번에는 정말로 근무 서기 시간을 고를 수 있습니다.** 0.12.2 에서는 **🪖 근무 서기**에 마우스를 올리면 하위 메뉴가
깜빡이다 사라지고, 메뉴째 닫힐 때도 많아 시간을 고를 수 없었습니다. 0.12.1 부터 앱은 아무도 보지 않을 때 이등병을
쉬게 하려고 메뉴바 아이콘이 가려졌는지 지켜봅니다. 이 알림은 메뉴·하위 메뉴를 포함해 앱의 창이 열리고 닫힐 때마다
오는데, 올 때마다 메뉴 전체가 다시 만들어졌습니다. 다시 만든 하위 메뉴 창이 또 알림을 불러, 하위 메뉴에 마우스를
올려 두면 초당 10~30번 반복됐습니다. 이제 값이 바뀔 때만 알리고, 메뉴바 아이콘만 그 값을 지켜봅니다. (#77)

이 릴리스는 중요 수정으로 표시하지 않았습니다. 이 버그는 메뉴에서 시간제 근무를 시작하지 못하게 했지만 데이터를
잃거나 보안을 약하게 하지 않았고, 에이전트 근무·배터리 하한·폭염 대응은 그대로 작동했습니다.
