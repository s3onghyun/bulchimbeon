## English

**The first notarized release.** Bulchimbeon for macOS is now signed with a Developer ID, notarized by Apple and
stapled, both the GitHub zip and the Homebrew cask. The first launch no longer needs **Open Anyway** in System
Settings: the app just opens, and at most macOS asks once whether to open an app downloaded from the internet.
Notifications now come from Bulchimbeon itself instead of **"Script Editor"**; allow them when macOS asks.

**Installed from the zip? Download this version once by hand.** The in-app updater only replaces the app with one
signed by the same team. Earlier versions are ad-hoc signed and have no team, so "New version 0.12.6 — Update"
stops with *"Could not update: The new app is signed by a different team than this one"* and leaves the installed
app as it is. Click **Open release page**, download `Bulchimbeon-0.12.6.zip` below and move the app to
`/Applications`, replacing the old one. From then on, in-app updates work again. Homebrew users are not affected:
`brew upgrade` replaces the app as usual.

**Notarization waits out a slow Apple.** The release workflow used to give up after 30 minutes when Apple was slow
to process a submission. It now submits without waiting, prints the submission id right away and checks the status
every 30 seconds for up to 90 minutes, so a slow day delays the release instead of failing it. (#87)

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or `brew install --cask s3onghyun/tap/bulchimbeon`
  for a new install. Or download `Bulchimbeon-0.12.6.zip` below (if you installed from the zip before, this is
  the way to update this time; see above).
- **Linux:** nothing changes for the Linux daemon in this release. Homebrew, AUR, tarball, `.deb` and `.rpm`
  installation instructions are in [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick
  one method only, so that only one daemon runs.

Check that macOS accepts the app with `spctl -a -vv /Applications/Bulchimbeon.app`: it prints
`source=Notarized Developer ID`. Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.12.6/CHANGELOG.md).

## 한국어

**첫 공증 릴리스입니다.** macOS 용 불침번을 이제 Developer ID 로 서명하고 Apple 공증을 받아 staple 합니다. GitHub zip 과
Homebrew cask 모두 해당합니다. 첫 실행에 시스템 설정의 **그래도 열기**가 더 이상 필요 없습니다. 앱이 그냥 열리고, 기껏해야
인터넷에서 내려받은 앱을 열지 macOS 가 한 번 묻습니다. 알림도 **"스크립트 편집기"** 대신 불침번 이름으로 옵니다. macOS 가
알림 허용을 물으면 허용하세요.

**zip 으로 설치했다면 이번 버전은 한 번 직접 내려받으세요.** 앱 안 업데이트는 같은 팀이 서명한 앱으로만 바꿉니다. 이전
버전은 ad-hoc 서명이라 팀이 없어서, "새 버전 0.12.6 — 업데이트"가 *"업데이트하지 못했습니다: 새 앱의 서명 팀이 지금 앱과
다릅니다"* 로 멈추고 설치된 앱은 그대로 둡니다. **릴리스 페이지 열기**를 눌러 아래 `Bulchimbeon-0.12.6.zip` 을 받아
`/Applications` 의 앱을 바꾸세요. 그다음부터는 앱 안 업데이트가 다시 됩니다. Homebrew 사용자는 영향이 없습니다.
`brew upgrade` 가 평소처럼 앱을 바꿉니다.

**Apple 이 느려도 공증을 기다립니다.** 릴리스 워크플로는 Apple 의 공증 처리가 30분을 넘기면 포기했습니다. 이제 기다리지
않고 제출해 제출 id 를 바로 출력하고, 30초마다 상태를 물어 최대 90분 기다립니다. Apple 이 느린 날에는 릴리스가 실패하지
않고 늦어질 뿐입니다. (#87)

### 설치

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, 새 설치는 `brew install --cask s3onghyun/tap/bulchimbeon`.
  또는 아래 `Bulchimbeon-0.12.6.zip`을 받으세요 (전에 zip 으로 설치했다면 이번에는 이 방법으로 올립니다. 위 참고).
- **Linux:** 이번 릴리스에서 리눅스 데몬은 바뀌지 않습니다. Homebrew·AUR·tarball·`.deb`·`.rpm` 설치는
  [README → Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1)을 보세요. 데몬이 하나만 돌도록 설치
  방법은 하나만 고르세요.

`spctl -a -vv /Applications/Bulchimbeon.app` 으로 macOS 가 앱을 받아들이는지 확인할 수 있습니다:
`source=Notarized Developer ID` 가 나옵니다. 릴리스 파일은 게시된 SHA-256 체크섬으로 검증한 뒤
`gh attestation verify <파일> --repo s3onghyun/bulchimbeon`을 실행하세요.
