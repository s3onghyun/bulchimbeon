## English

### Highlights

- **Simplified Chinese UI.** The menu, status, settings and soldier lines are now available in
  Simplified Chinese, alongside Korean and English. Choose it from the language menu or let the
  app follow a Chinese system language. (#27)
- **Desert uniform.** Pick the new **Desert** option from the **🎽 Uniform** menu. It uses
  generic sand and tan colors only—never a real army uniform or pattern. (#26, closes #20)
- **Lighter macOS scans.** Processes whose arguments cannot affect agent matching now avoid an
  unnecessary `KERN_PROCARGS2` read on later scans. The icon animation timer also has tolerance,
  reducing needless wakeups. Process arguments are not cached, and exited processes are forgotten.
  (#31)

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.7.1.zip` below.
- **Linux:** Homebrew, tarball and `.deb` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.7.1/CHANGELOG.md).

## 한국어

### 주요 변경

- **간체 중국어 UI.** 메뉴·상태·설정·이등병 대사를 한국어·영어와 함께 간체 중국어로 쓸 수 있습니다.
  언어 메뉴에서 고르거나 중국어 시스템 언어를 따르게 할 수 있습니다. (#27)
- **사막 군복.** 메뉴 **🎽 군복**에서 새 **사막** 군복을 고릅니다. 모래색·황갈색의 가상 색상만 쓰며,
  실제 군대의 복장이나 문양은 쓰지 않습니다. (#26, #20 해결)
- **가벼워진 macOS 점검.** argv 가 에이전트 판별에 영향을 주지 않는 프로세스는 다음 점검에서 불필요한
  `KERN_PROCARGS2` 읽기를 하지 않습니다. 아이콘 애니메이션 타이머에도 tolerance 를 주어 불필요한
  깨어남을 줄였습니다. 프로세스 argv 는 캐시하지 않고, 종료된 프로세스는 잊습니다. (#31)

### 설치

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, 새 설치는
  `brew install --cask s3onghyun/tap/bulchimbeon`. 또는 아래 `Bulchimbeon-0.7.1.zip`을 받으세요.
- **Linux:** Homebrew·tarball·`.deb` 설치는 [README → Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1)을
  보세요. 데몬이 하나만 돌도록 설치 방법은 하나만 고르세요.

릴리스 파일은 게시된 SHA-256 체크섬으로 검증한 뒤
`gh attestation verify <파일> --repo s3onghyun/bulchimbeon`을 실행하세요.
