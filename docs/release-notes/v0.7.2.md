## English

### Highlights

- **Check mark on the chosen watch.** In the **🪖 Stand watch** menu, the duration you picked,
  including *Indefinitely*, now shows a check mark, so you can see at a glance what you chose. A
  timed watch resumed after a restart shows no check mark. (#38)
- **Ideas and questions in Discussions.** GitHub
  [Discussions](https://github.com/s3onghyun/bulchimbeon/discussions) is open for ideas and
  questions. The feature-request form is shorter and in English, Simplified Chinese and Korean,
  and the READMEs link to Ideas. (#37)
- **Core tests on Linux.** `BulchimbeonCore` now builds and its tests run on Linux; macOS builds
  are unchanged. This also fixes a custom agent name check that accepted a name ending in a
  newline. (#34)
- Contributor process: CODEOWNERS now marks `go.mod`, `go.sum` and `packaging/` as
  security-sensitive, and the translation issue form is labeled `translation`. (#35, #33)

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.7.2.zip` below.
- **Linux:** Homebrew, tarball and `.deb` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.7.2/CHANGELOG.md).

## 한국어

### 주요 변경

- **고른 근무에 체크 표시.** 메뉴 **🪖 근무 서기**에서 고른 시간 항목(무기한 포함)에 체크 표시가 붙어,
  무엇을 골랐는지 바로 볼 수 있습니다. 재시작 후 이어진 근무에는 표시하지 않습니다. (#38)
- **아이디어·문의는 Discussions로.** GitHub [Discussions](https://github.com/s3onghyun/bulchimbeon/discussions)에서
  아이디어와 질문을 받습니다. 기능 제안 양식은 영어·간체 중국어·한국어로 짧아졌고, README 에 Ideas 링크를
  달았습니다. (#37)
- **리눅스에서 Core 테스트.** `BulchimbeonCore` 를 리눅스에서도 빌드하고 테스트할 수 있습니다. macOS 빌드는
  그대로입니다. 끝에 줄바꿈이 붙은 사용자 정의 에이전트 이름을 받아들이던 문제도 고쳤습니다. (#34)
- 기여 절차: CODEOWNERS 가 `go.mod`·`go.sum`·`packaging/` 을 보안 민감 경로로 표시하고, 번역 이슈 양식에
  `translation` 라벨을 답니다. (#35, #33)

### 설치

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, 새 설치는
  `brew install --cask s3onghyun/tap/bulchimbeon`. 또는 아래 `Bulchimbeon-0.7.2.zip`을 받으세요.
- **Linux:** Homebrew·tarball·`.deb` 설치는 [README → Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1)을
  보세요. 데몬이 하나만 돌도록 설치 방법은 하나만 고르세요.

릴리스 파일은 게시된 SHA-256 체크섬으로 검증한 뒤
`gh attestation verify <파일> --repo s3onghyun/bulchimbeon`을 실행하세요.

전체 변경 목록: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.7.2/CHANGELOG.md).
