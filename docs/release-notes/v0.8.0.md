## English

### Highlights

- **Linux tray icon.** `bulchimbeon tray` puts the private in your desktop panel (XFCE status
  tray, KDE, or GNOME with the AppIndicator extension), with the same poses and pace as the
  macOS menu bar. The menu mirrors every line of `bulchimbeon status` and offers **🧥 Uniform**
  and a close item (the daemon keeps standing watch). (#42)
  - The `.deb` installs an autostart entry in `/etc/xdg/autostart`, and `install-linux.sh`
    adds one in `~/.config/autostart`, so the tray starts with your desktop session. You can
    also run `bulchimbeon tray` by hand.
  - On GNOME, the tray needs the AppIndicator extension. Ubuntu ships it; Fedora does not, so
    install it there first.
  - Without a session bus or tray host (SSH, headless machines), the tray logs one line and exits.
- **Uniform on Linux.** `uniformTheme` is now settable on Linux, from the tray's Uniform menu
  or with `bulchimbeon config set uniformTheme navy`. (#42)

### Known limitations

- On some Linux desktops, idle and suspend blocking does not behave as intended. The next
  release reworks it to use each desktop's own power API.

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.8.0.zip` below.
- **Linux:** Homebrew, tarball and `.deb` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.8.0/CHANGELOG.md).

## 한국어

### 주요 변경

- **리눅스 트레이 아이콘.** `bulchimbeon tray` 가 데스크톱 패널(XFCE 상태 트레이, KDE, GNOME
  AppIndicator 확장)에 이등병을 맥 메뉴바와 같은 자세·속도로 띄웁니다. 메뉴에는
  `bulchimbeon status` 의 모든 줄, **🧥 군복** 선택, 트레이 닫기(데몬은 계속 근무)가 있습니다. (#42)
  - `.deb` 는 `/etc/xdg/autostart`, `install-linux.sh` 는 `~/.config/autostart` 에 자동 시작
    항목을 두어 데스크톱 세션과 함께 트레이가 뜹니다. 직접 `bulchimbeon tray` 로 띄워도 됩니다.
  - GNOME 에서는 AppIndicator 확장이 필요합니다. Ubuntu 는 기본 포함, Fedora 는 따로 설치하세요.
  - 세션 버스나 트레이 호스트가 없으면(SSH, 헤드리스) 한 줄만 남기고 끝납니다.
- **리눅스에서도 군복.** `uniformTheme` 을 리눅스에서도 설정할 수 있습니다. 트레이의 군복 메뉴나
  `bulchimbeon config set uniformTheme navy` 를 쓰세요. (#42)

### 알려진 제한

- 일부 리눅스 데스크톱에서 유휴·절전 막기가 의도대로 동작하지 않습니다. 다음 릴리스에서 각
  데스크톱의 전원 API 를 쓰도록 고칩니다.

### 설치

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, 새 설치는
  `brew install --cask s3onghyun/tap/bulchimbeon`. 또는 아래 `Bulchimbeon-0.8.0.zip`을 받으세요.
- **Linux:** Homebrew·tarball·`.deb` 설치는 [README → Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1)을
  보세요. 데몬이 하나만 돌도록 설치 방법은 하나만 고르세요.

릴리스 파일은 게시된 SHA-256 체크섬으로 검증한 뒤
`gh attestation verify <파일> --repo s3onghyun/bulchimbeon`을 실행하세요.
