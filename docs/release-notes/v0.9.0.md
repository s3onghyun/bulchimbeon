## English

### Highlights

- **Fedora and RHEL-family `.rpm`.** The release page now has
  `bulchimbeon-0.9.0-1.x86_64.rpm` and `bulchimbeon-0.9.0-1.aarch64.rpm`, with the same files
  as the `.deb` (the same binary as the tarball). Install it with:

  ```sh
  sudo dnf install ./bulchimbeon-0.9.0-1.x86_64.rpm
  ```

  The package installs the systemd user unit but does not enable it. Each user enables it with
  `systemctl --user enable --now bulchimbeon`. The `.rpm` files are in `SHA256SUMS` and carry
  build provenance attestations. (#47)
- **Arch (AUR) and Fedora COPR: coming soon.** The recipes are prepared in the repository
  (`packaging/aur`, `.copr`) but are not published yet.

macOS: no change. Linux daemon: no change.

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download
  `Bulchimbeon-0.9.0.zip` below.
- **Linux:** Homebrew, tarball, `.deb` and `.rpm` installation instructions are in
  [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1). Pick one method only,
  so that only one daemon runs.

Verify any release file with its published SHA-256 checksum, then run
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.

Full list of changes: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.9.0/CHANGELOG.md).

## 한국어

### 주요 변경

- **Fedora·RHEL 계열 `.rpm`.** 릴리스 페이지에 `bulchimbeon-0.9.0-1.x86_64.rpm`·
  `bulchimbeon-0.9.0-1.aarch64.rpm` 이 생겼습니다. `.deb` 와 같은 파일(tarball 과 같은 바이너리)입니다.
  설치:

  ```sh
  sudo dnf install ./bulchimbeon-0.9.0-1.x86_64.rpm
  ```

  패키지는 systemd 사용자 유닛을 설치만 하고 켜지 않습니다. 사용자마다
  `systemctl --user enable --now bulchimbeon` 으로 켜세요. `.rpm` 도 `SHA256SUMS` 와 빌드 출처 증명에
  들어갑니다. (#47)
- **Arch(AUR)·Fedora COPR: 곧 제공.** 레시피는 저장소에 준비되어 있지만(`packaging/aur`, `.copr`)
  아직 공개되지 않았습니다.

macOS: 변경 없음. 리눅스 데몬: 변경 없음.

### 설치

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, 새 설치는
  `brew install --cask s3onghyun/tap/bulchimbeon`. 또는 아래 `Bulchimbeon-0.9.0.zip`을 받으세요.
- **Linux:** Homebrew·tarball·`.deb`·`.rpm` 설치는 [README → Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1)을
  보세요. 데몬이 하나만 돌도록 설치 방법은 하나만 고르세요.

릴리스 파일은 게시된 SHA-256 체크섬으로 검증한 뒤
`gh attestation verify <파일> --repo s3onghyun/bulchimbeon`을 실행하세요.

전체 변경 목록: [CHANGELOG.md](https://github.com/s3onghyun/bulchimbeon/blob/v0.9.0/CHANGELOG.md).
